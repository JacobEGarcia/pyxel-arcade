# Pyxel Arcade

Ten small 3D games built on the Pyxel 3.0 development preview (engine pinned at upstream commit c8d2274, loaded from jsdelivr on first play; internet required).

Play via the Pages site's index.html. Python sources sit beside each game page and are also embedded in the HTML. Note: each game page carries a small CSS override keeping div#pyxel-screen in flow so the on-screen touch controls stay reachable (the engine's default stylesheet takes the screen full-viewport).
