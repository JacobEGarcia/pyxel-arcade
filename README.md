# Jacob's arcade

A small collection of 2D and 3D games built on the Pyxel 3.0 development preview (engine pinned at upstream commit c8d2274, loaded from jsdelivr on first play; internet required).

Play at https://jacobegarcia.github.io/pyxel-arcade/

Featured games: Towerfall Lab (3D physics), Bell Garden (2D rhythm), Orbit Orchard (3D exploration), Coin Trail (2D maze), Koban Toss (3D target game), and Skyline Stack (3D timing game). Seven more experiments are linked under "Elsewhere in the arcade" on the site.

Python sources sit beside each game page and are also embedded in the HTML. Note: each game page carries a small CSS override keeping div#pyxel-screen in flow so the on-screen touch controls stay reachable (the engine's default stylesheet takes the screen full-viewport).
